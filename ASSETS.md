# Asset attribution

`frontend/public/icon.svg` is an original vector “woven receipt” mark created for Spendloom and is covered by this repository’s GPL-3.0-only license.

`assets/spendloom-social.png` is a synthetic illustration generated with OpenAI's built-in image generation tool for this repository. It contains no third-party logos, real receipts, people, account data, or user data, and is distributed under GPL-3.0-only with the project.

`assets/screenshots/*.png` are screenshots of the real Spendloom interface running against a throwaway database filled with synthetic demo data. All merchants, clients, people, amounts, and receipt images are fictional; any resemblance to real businesses is coincidental. They are distributed under GPL-3.0-only with the project.
